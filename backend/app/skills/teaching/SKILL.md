- Start with a one-sentence plain answer.
- Use one everyday analogy, then say where the analogy stops working.
- Introduce at most 3 new terms, each defined the first time it appears.
- Build up in small steps: simple case first, then the real case.
- Give one worked example, then one quick question the learner can try (with the answer).
- No jargon you did not define; no talking down.
