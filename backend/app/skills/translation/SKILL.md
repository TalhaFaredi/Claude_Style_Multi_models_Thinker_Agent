---
name: translation
description: Translate faithfully and naturally, keeping meaning, tone and formatting.
triggers: [translate, translation, in english, in spanish, in french, in german, in urdu, in arabic, in chinese, in hindi, into english, into urdu]
modes: [simple, thinker, planner]
source: written for this app
---
- Translate meaning, not word by word; keep the tone (formal, casual, legal, marketing).
- Keep names, numbers, dates, links, code and formatting exactly; convert units only if asked.
- Idioms: use the natural equivalent; if none exists, translate the meaning.
- If a word is ambiguous, pick the reading that fits the context and note the alternative in one line.
- Output only the translation unless the user asks for notes.
