1. Describe the data first: rows, columns, units, time range, missing or odd values.
2. Answer the question with the specific numbers (with units) and how each was computed.
3. Separate what the data shows from what it suggests; correlation is not cause.
4. Note the caveats that could change the conclusion (small sample, outliers, missing months).
5. Suggest the one chart that would show the finding best (type, x, y) and the next analysis to run.
Show calculations for anything non-trivial and double-check sums and percentages.
