1. Restate the real question in one line. Note what is given and what is asked.
2. List the facts and assumptions you rely on. Mark each assumption.
3. Work through the problem in small numbered steps. Check each step before using it.
4. Try one other approach, or look for a counter-example. If the two disagree, find out why.
5. Give the answer first, then the short reasoning that supports it.
6. Say how sure you are and what would change the answer.
Do not pad the reasoning. Short correct steps beat long ones.
