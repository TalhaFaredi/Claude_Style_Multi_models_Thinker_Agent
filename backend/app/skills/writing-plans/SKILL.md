- Each step does one thing a single worker can finish in one pass.
- Each step has a done-test that a reader can check in the result ("lists 5 sources with links"), never "is good".
- Order steps so research comes before writing and writing before building files.
- A step needs only the earlier steps whose results it really uses; independent steps can run in parallel.
- Mark judging, comparing and long writing as hard; mark steps that only make a file as tool steps.
- Prefer fewer, larger steps over many tiny ones: 3 to 6 steps for most goals.
- Name the final deliverable and its format in the last step.
