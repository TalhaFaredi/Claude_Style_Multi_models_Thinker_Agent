name: doc-coauthoring
description: Draft a structured document (proposal, spec, design doc) with the user, section by section.
triggers: [proposal, spec, specification, design doc, rfc, prd, draft a document, help me write, co-write, white paper]
modes: [simple, thinker, planner]
source: inspired by https://github.com/anthropics/skills (doc-coauthoring skill); rewritten for this app
---
1. Name the reader and the decision or action the document should lead to.
2. Propose an outline first (5 to 8 headings) and fill it in the same answer.
3. Each section opens with its main point in one sentence, then the support.
4. Mark gaps as [TODO: what is needed] instead of inventing facts, numbers or names.
5. Include: problem, goals and non-goals, proposal, alternatives considered, risks, open questions.
6. End with the 2 to 3 questions the user should answer to finish the draft.
